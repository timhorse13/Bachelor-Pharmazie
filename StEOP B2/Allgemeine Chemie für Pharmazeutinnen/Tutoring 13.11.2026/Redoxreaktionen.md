## Grundlage
### Reduktion: 
- Aufnahme von Elektronen
- Stockzahl wird reduziert
- Oxidationszahl wird reduziert
### Oxidation
- Abgabe von Elektronen
## Reduktionsmittel
- ist ein Stoff der andere Stoffe reduziert = gibt e⁻ her
- wird dabei oxidiert
- ist üblicherweise stark reduziert
- z.b.:
	- Cr⁰
	- Cl⁻
	- I⁻
	- Br⁻
## Oxidationsmittel
- z.b.:
	- ERGÄNZEN!

## Oxidationszahlen ermitteln
- Elementarer Zustand -> Ox-Zahl = 0
$\Large Fe^0 \space H_2 \space Cl_2 \space O_2$ -> 0
- Ionen -> Ox-Zahl = [[Ionenwertigkeit und Ionenladungen zum merken (VON KI ERSTELLT)|Ionenwertigkeit]]

### Bei kovalenten Bindungen
- C=C, N-N, O-O, N=N, C-C,...
	-> Bindungselektronen aufgeteilt (beide +0)

### Jetzt gehts los
- Höhere EN -> +1      EN_O = 3,5 (H2O)
- Niedrigere EN -> -1  EN_H = 2,2

> Wasserstoff = +I (außer mit Li/Na/etc.)
> Fluor = -I immer
> Sauerstoff = -II (außer bei O-O, O-F)

- Beispiel Chlor:
	- Chlor ist in der 7 Hauptgruppe
	 -> Maximum = +VII (ClO⁴⁻)
	 -> Minumum = -I (Cl⁻)

- Die Summe aller Oxidationszahlen = Ladung des Moleküls
$\Large ClO_4^- \to +VII + 4^*(-II) = -1$ 

- Redox-Gleichungen
1. Halbgleichungen aufstellen
2. Halbgleichungen sauer/basisch ausgleichen
3. ELektronen bei Halbgleichungen miteinbeziehen
4. Addition zur Gesamtgleichung

## HÄ 1
- Chromat reagiert im sauren Milleu mit Sulfit zu Chrom(III) und Sulfat

I: $\Large CrO_4^{2-} + 8H^+ + 6e^- \to Cr^{3+} + 4H_2O$
**Ladungen zählen:**
- links: -2 + (+8) = +6
- rechts: +3
Also links 3 e⁻ dazu

II: $\Large SO_3^{2-} + H_2O \to SO_4^{2-} + 2H^+ + 2e^-$ 
**Ladungen zählen:**
- links: -2
- rechts -2 + (+2) = 0
Also rechts 2 e⁻ dazu

**Gesamtgleichung:**
$\Large CrO_4^{2-} + 8H^+ + 6e^- + SO_4^{2-} + 2H^+ + 2e^- \to Cr^{3+} + 4H_2O + \Large SO_3^{2-} + H_2O$ 
$\Large CrO_4^{2-} + 10H^+ + 8e^- + SO_4^{2-} + \to Cr^{3+} + 5H_2O + SO_3^{2-}$ 

> im sauren: H20 und H⁺
> wenn sauer/basisch nicht angegeben dann kann man aussuchen
