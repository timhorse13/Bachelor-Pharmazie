# Meine (hoffentlich bald nicht nur meine) Notizen, Zusammenfassungen, Übungen, etc. zum Pharmazie-Bachelor

## Wichtig:
Alle Notizen sind mithilfe der Software **Obsidian** erstellt worden. Für bestimmte Funktionen, die ein normaler Markdown-Viewer (wie Glow) nicht unterstützt (wie Verlinkung von anderen Notizen, out-of-box Support für Latex Formeln, etc.) ist es Sinnvoll Obisidian (https://obsidian.md/) zuerst zu installieren und anschließend die Repository herunterzuladen/clonen.
