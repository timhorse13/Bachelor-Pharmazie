# Meine (hoffentlich bald nicht nur meine) Notizen, Zusammenfassungen, Übungen, etc. zum Pharmazie-Bachelor

## Wichtig:
Alle Notizen sind mithilfe der Software Obsidian erstellt worden. Um bestimmte Funktionen, die ein normaler Markdown-Viewer nicht unterstützt (wie Verlinkung von anderen Notizen, out-of-box Support für Latex Formeln, etc.) ist es Sinnvoll Obisidian (https://obsidian.md/) zu installieren und anschließend die Repository herunterzuladen.
